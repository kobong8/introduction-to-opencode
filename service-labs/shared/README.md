# 나의 할 일 목록

1. ZIP을 압축 해제합니다. 안쪽 폴더에 `install.ps1`이 보이면 그 폴더에서 PowerShell을 엽니다.
2. `.\install.ps1`을 실행합니다. Python 편은 Python 3.10 이상, Node.js 편은 Node.js 22.13 이상이 준비되어 있어야 합니다.
3. `.\start.ps1`을 실행하고 주소를 브라우저에서 엽니다. 기본 포트는 Python 8000, Node.js 3000입니다.
4. 할 일 두 개를 추가하고 하나를 완료합니다. 새로고침해도 같은 상태인지 확인합니다.
5. 첫 창에서 `Ctrl+C`로 서버를 종료하거나, PowerShell을 하나 더 열고 `.\test.ps1`을 실행합니다. Python에서는 `OK`, Node.js에서는 `pass 1`을 확인합니다.

사내 PC에서 런타임이나 스크립트 실행이 막혀 있으면 사내 설치·실행 안내를 확인하세요. 이 예제의 서버는 내 컴퓨터에서만 열립니다.

## 파일을 어디서 고치나요?

- `public/index.html`은 화면 구조와 스타일입니다.
- `public/app.js`는 브라우저에서 버튼을 누를 때 실행됩니다.
- `app.py` 또는 `server.mjs`는 API를 제공하고 SQLite에 저장합니다.
- `test_service.py` 또는 `test.mjs`는 조회·추가·완료 변경·재실행 후 데이터 보존을 확인합니다.
- `tasks.db`는 첫 서버 실행 때 생깁니다. 테스트는 별도의 임시 데이터베이스를 사용합니다.

## OpenCode에 줄 첫 작업

```text
현재 화면과 코드를 먼저 읽고 바꿀 파일과 확인 방법을 알려줘.
미완료만 보기와 전체 보기 버튼을 추가하고, 완료 항목은 미완료 화면에서만 숨겨줘.
할 일 두 개를 추가하고 하나를 완료한 뒤, 모드를 바꿨을 때 예상한 항목이 보이는지 확인해줘.
관련 없는 기능은 건드리지 말고, 실행한 테스트와 결과를 알려줘.
```

포트가 이미 사용 중이면 `.\start.ps1 -Port 8010`처럼 다른 번호를 지정할 수 있습니다.
